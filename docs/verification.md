## 复现组件渲染

在仓库根目录构建后运行：

```bash
build/Notification.app/Contents/MacOS/Notification --render-preview build/preview.png
```

该命令只渲染合成通知，不读取系统通知，也不代表浮层已在各个物理屏幕显示。

## 真实消息验收方法

先确认菜单的系统通知状态为「监听中」，再从常用应用各产生数条新通知，逐条记录系统是否出现、浮层是否出现、是否在所有屏幕出现、出现延迟及有无重复。分母应为本轮系统实际收到的通知数，不能把未发送成功的消息计算成工具漏收。批量突发、立即清除和通知更新分别测试。

可先在设置窗口点击「发送系统通知测试」，等待「已从通知中心读回并展示」，再点击「打开最近测试的原通知」。确认「已收到此条原通知的默认点击」；仅弹出通知中心或展开通知组不算消息点击成功。其他应用还需检查实际定位到对应消息，并验证原卡片被清除、同文多条、折叠和隐藏预览时的退路。

Codex 验证需使用实际会触发审批的测试会话，并在原 CLI 中完成批准或拒绝；另行触发一条真实提问，确认回答后相应提醒清除。手动发送的样例 JSON 仅验证桥接与展示，不计为真实 Codex 事件验证。
